# PhoenixChain Security Notes

PhoenixChain Core Prototype v0.1 is not production mainnet software.

Security warnings:

- not audited
- consensus is a prototype
- P2P is a prototype
- no slashing
- no staking
- no smart contracts
- no bridge
- no persistent state
- no real network sync
- no mainnet

Private keys must not be hardcoded. The v0.1 CLI can generate wallets and print
keys for local development only. A local encrypted keystore is future work.
