# Validator Network

PhoenixChain is being shaped as a validator-secured network, not a single-node demo with explorer cosmetics.

## Current Posture

- devnet validator set exists
- validator operations and health are visible
- proposer and runtime monitoring foundations exist

## What Still Matters

- external validator onboarding
- region diversity
- stronger recovery playbooks
- decentralization proof
- mainnet-grade key management

## Why This Matters

The chain cannot claim legitimacy if validator reality is weaker than validator branding.
