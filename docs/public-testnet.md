# PhoenixChain Public Testnet Plan

PhoenixChain is not public-testnet-ready yet, but v0.6 prepares the path.

## Required Systems

- public RPC cluster
- explorer deployment
- faucet
- validator onboarding
- node setup documentation
- metrics dashboard
- uptime monitoring
- abuse prevention
- chain reset policy
- genesis coordination

## Test PHX Distribution

Test PHX has no real value. Distribution should occur through a rate-limited
faucet and validator allocations.

## Entry Criteria

- stable devnet for multiple weeks
- faucet abuse protection
- external validator docs
- monitoring alerts
- security checklist complete
