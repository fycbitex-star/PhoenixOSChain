# PhoenixOS Native Integration

PhoenixChain should integrate into PhoenixOS only after the APIs are stable.

## Integration Areas

- Phoenix Wallet
- PHX payments
- AI agent payment hooks
- strategy marketplace payments
- subscription billing hooks
- on-chain audit logs
- transaction history APIs
- identity-to-wallet mapping
- chain status widgets
- chain analytics APIs

## Current Status

The integration is architectural. Real custody and payments are not enabled.

## Next Steps

- read-only wallet status
- chain status widget
- transaction history API
- policy-controlled AI payment intents
