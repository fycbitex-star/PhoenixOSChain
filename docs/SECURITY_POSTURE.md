# Security Posture

PhoenixChain is published with a professional security posture, not a fake one.

## What Is Expected Before Mainnet

- protocol review
- threat model validation
- key management hardening
- governance and treasury safety enforcement
- validator recovery rehearsal
- RPC abuse resistance
- explorer and indexer integrity

## What This Repository Does Well

- makes architecture visible
- documents security intent
- exposes mainnet blockers honestly

## What This Repository Does Not Pretend

- it does not pretend unfinished systems are audited
- it does not pretend devnet validator structure is mainnet decentralization
- it does not pretend treasury safety is complete without execution controls
