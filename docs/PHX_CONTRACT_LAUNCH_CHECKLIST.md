# PHX Contract Launch Checklist

This checklist exists so PhoenixChain never publishes an "official PHX contract" before the surrounding legitimacy stack is real.

## 1. Monetary Freeze

- maximum supply confirmed
- decimals confirmed
- allocation buckets approved
- treasury policy aligned with public docs
- genesis allocation inputs frozen

## 2. Governance Freeze

- governance authority for official asset publication identified
- emergency override process documented
- public explanation of native vs wrapped asset model published

## 3. Treasury and Signer Discipline

- treasury multisig participants selected
- threshold documented
- signer key ceremony completed
- signer storage and recovery policy documented
- emergency rotation path documented

## 4. Validator and Network Readiness

- validator set confirmed
- chain parameters frozen
- genesis reproducibility verified
- launch coordination window agreed

## 5. Security

- contract review completed
- signer workflow reviewed
- bridge architecture reviewed if external representation is involved
- final public address publication reviewed by operator and treasury lanes

## 6. Public Communication

- canonical asset statement published
- official address publication policy published
- warning against fake or unofficial contracts published
- explorer and wallet metadata updated

## 7. External Representation Rules

If PHX is represented elsewhere:

- representation must clearly say wrapped or bridged
- mint and redeem authority must be documented
- bridge or custody trust model must be published
- official address list must be maintained in one canonical location

## Stop Conditions

Do **not** publish an official PHX contract if any of the following remain true:

- genesis allocation still moves
- treasury signer posture is unclear
- governance authority is ambiguous
- bridge trust model is undocumented
- public docs still blur native PHX and wrapped PHX

## Success Condition

The market should be able to answer all of these questions unambiguously:

- what is the canonical PHX asset?
- is it native or contract-based?
- if a contract exists, is it root or wrapped?
- who controls issuance or bridge minting?
- where is the official published address list?
